# ทดลองข้อมูล VPS ในเครื่อง

รันบน Terminal ของ Mac โดยไม่ต้อง SSH เข้า VPS ก่อน:

```sh
cd /Users/torz.athan/@Projects/Twiniiz/kruhub
sh scripts/pull-vps-data.sh
```

สคริปต์เชื่อมต่อ `root@143.14.9.30` ให้เอง อาจถามรหัส SSH สองครั้ง ดึงฐานข้อมูล Kru-Hub และไฟล์ใน `/app/uploads` ของ Kru-Hub มาเก็บที่ `backups/vps-kruhub-full-.../` พร้อม checksum โดยไม่อัปเดต หยุด หรือแก้ข้อมูลบน VPS และไม่ทับฐานข้อมูล local หรือ `backend/.env`

ระหว่างดึงให้เว้นการแก้ตารางและอัปโหลด/ลบเอกสารบน VPS เพราะฐานข้อมูลกับไฟล์ถูกอ่านคนละจังหวะ หากมีไฟล์เปลี่ยนระหว่างทาง สคริปต์อาจหยุด ต้องดึงใหม่หรือยืนยันความครบถ้วนก่อนนำเข้า

เมื่อเสร็จ ส่งเฉพาะ path โฟลเดอร์ให้ผู้ช่วยดำเนินการต่อ ไม่ต้องส่งไฟล์ฐานข้อมูลหรือเอกสารเข้าแชต และห้ามนำขึ้น Git

ขั้นตอนนำเข้าที่ต้องทำหลังดาวน์โหลด:

1. ตรวจ checksum ทั้งสองไฟล์ และตรวจชื่อไฟล์ใน archive ก่อนแตกไฟล์
2. สร้างฐานข้อมูล local ชื่อใหม่และโฟลเดอร์ uploads แยก เก็บข้อมูล local เดิมไว้
3. นำเข้าฐานข้อมูล ตรวจว่ามีไฟล์ที่อ้างอิงจากฐานข้อมูลครบ และตรวจสถานะจริงของตารางเดิม
4. สำรอง `backend/.env` แล้วเปลี่ยนเฉพาะค่าการเชื่อมต่อ local และ uploads ห้ามใช้ค่าการเชื่อมต่อ VPS
5. รัน migration กับสำเนา local เท่านั้น เปรียบเทียบคาบเดิมก่อน/หลังและตรวจว่าฉบับที่ต้องการถูกเลือก
6. เปิดระบบที่ `http://127.0.0.1:5174/` เพื่อทดสอบ การกด Auto แก้คาบ หรือบันทึกเสร็จจะมีผลเฉพาะสำเนา local

ใช้บัญชีผู้ใช้จาก VPS เข้า local ได้หลังนำเข้าข้อมูล ไม่ต้องสร้างบัญชีใหม่ สคริปต์นี้ไม่ได้คัดลอกค่าลับของ production environment หรือการตั้งค่า Nginx/SSL

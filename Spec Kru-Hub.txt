เช่น
โรงเรียน , ชั้นการเรียน , ห้องเรียนแต่ละชั้น , รายวิชา , บุคลากร(อาจจะเก็บบุคลากรที่นอกเหนือจากครูด้วยเผื่ออนาคตอาจจะมีระบบภายในโรงเรียนด้วยเช่นระบบธุราการอะไรพวกนี้) , ข้อมูลนักเรียน(อนาคตอาจจะมีระบบเช็คชื่อนักเรียน)
ข้อมูลที่อยากให้แต่ละโรงเรียนที่เอาระบบไปใช้มีคือ
โรงเรียนอะไร มีครูกี่คน ครูอยู๋หมวดวิชาอะไร โรงเรียนมีชั้นเรียนอะไรบ้าง แต่ละชั้นเรียนมีกี่ห้องเรียน แต่ละห้องเรียนต้องเรียนวิชาอะไรบ้าง เรียนกี่คาบต่อวัน เรียนวิชาละกี่คาบต่อสัปดาห์ ประมาณนี้นายลองช่วยคิดวิเคาะห์เพิ่มให้หน่อยนะว่าถ้าจากที่ฟังรายละเอียดแต่ละ function แล้วควรจะต้องมีเก็บข้อมูลอะไรเพิ่มบ้าง

ประเภท User ที่ใช้ระบบ
user super admin = คือเจ้าของระบบ
user admin(ประจำแต่ละโรงเรียน) = super admin จะเป็นคน generate user ให้
user บุคลากรของแต่ละโรงเรียน(ครู, พนักงานในโรงเรียน) = admin(ประจำแต่ละโรงเรียน) จะเป็นคน generate user ให้ 
user บุคคลภายนอกประเภทนักเรียน = บุคลากรของแต่ละโรงเรียน(ครูประจำชั้น) จะเป็นคน generate user ให้ (ถ้าขึ้นปีการศึกษาใหม่จะเคลียร์ข้อมูล user นักเรียนออกทั้งหมด) อาคตจะเอาไว้ดูรายชื่อการเช็คชื่อเข้าเรียนในแต่ละวิชาหรืออาจจะสามารถดูการบ้านแต่ละวิชาของนักเรียนได้
user บุคคลภายนอกประเภทผู้ปกครอง = บุคลากรของแต่ละโรงเรียน(ครูประจำชั้น) จะเป็นคน generate user ให้ (ถ้าขึ้นปีการศึกษาใหม่จะเคลียร์ข้อมูล user ผู้ปกครองออกทั้งหมด) อาคตจะเอาไว้ดูรายชื่อการเช็คชื่อเข้าเรียนในแต่ละวิชาหรืออาจจะสามารถดูการบ้านแต่ละวิชาของนักเรียนได้

เดี๋ยวเราจะมาอธิบายโซนแรกก่อนนะ
function แรก : จัดตารางเรียนตารางสอนของคุณครู
ฟังค์ชั่นนี้ เอาไว้ให้ครูใช้ในการจัดตารางสอนแบบอัตโนมัติ
การทำงานจะเป็นประมาณว่า ในแต่ละชั้นเรียนของแต่ละชั้นจะให้ครู 1 คนในการจัดตารางเรียน
การจะจัดตารางเรียนได้นั้นจะต้องมีข้อมูลก่อนว่า ชั้นเรียนนั้นมีครูคนไหนที่จะต้องสอนบ้างห้องไหนมีครูคนไหนสอน สอนวิชาอะไรจะต้องลงให้หมด
หลังจากลงหมดจะรู้ว่า ชั้นนี้มีกี่ห้องแต่ละห้องเรียนกี่คาบต่อสัปดาห์ในแต่ละวัน จันทร์ - ศุกร์ เรียบกี่คาบ แต่ละห้องจะต้องเรียนวิชาอะไรบ้างแต่ละวิชาจะต้องเรียนกี่คาบ และวิชาแต่ละวิชาของแต่ละห้องครูคนไหนเป็นคนสอน ครูที่สอนไม่จำเป็นจะต้องเป็นครูประจำหลักสูตรวิชา
เช่นครูอิ๋วเป็นครูหลักสูตรวิชาวิทยาศาสตร์ และเป็นครูประจำชั้น ประถม 5/4 แต่ครูอิ๋วสามารถสอนวิชาไทยก็ได้ หรือคณิตก็ได้
ในตอนที่กำหนดค่าพวกนี้จะต้องมีข้อมูงให้ดูตลอดด้วยว่า ครูที่เลือกมาสอนแต่ละคนมีตารางเวลาเป็นยังไงบ้าง และแต่ละห้องที่กำลังใส่ข้อมูลก็จะต้องดูได้ด้วยว่าในแต่ละห้องที่ใส่ข้อมูลเข้าไปใส่ไปกี่วิชาแล้ววิชาละกี่คาบแล้ว ใครเป็นคนสอนบ้าง และรวมทั้งหมดมีกี่คาบที่ต้องเรียนแล้ว
หลังจากจบขั้นตอนใส่ข้อมูลเบื้องต้นครบแล้ว
จะได้ข้อมูลที่พร้อมจัดตารางเรียนตารางสอนแบบนี้คือ
สมมุติเราจะยกตัวอย่างชั้นรียนประถม 5 นะ
เช่น ประถม 5 มีทั้งหมด 5 ห้องคือ ป.5/1 - ป.5/5 แต่ละห้องเรียนทั้งหมด 25 คาบ/สัปดาห์ เรียนวันและ 5 คาบ เรียน 5 วันต่อสัปดาห์
สิ่งที่ต้องพร้อมก่อนเริ่มจับคู่คือ ทุกห้องในชั้นเรียนนั้นจะต้องถูกระบบครบแล้วมีห้องเรียนจะต้องเรียนคาบตามที่กำหนดเช่น 25 คาบทุกห้อง และจะต้องมีวิชาตามที่กำหนดว่าแต่ละห้องจะเรียนวิชาอะไรบ้างจำนวนกี่คาบ
ถ้าห้องทุกห้องพร้อมครูพร้อม
ถึงจะแสดงปุ่มให้ Auto จัดตารางเรียนตารางสอน
แต่ก่อนที่จะให้ ระบบ Auto จัดให้ เราสามารถ manual จัดไปเองก่อนเลยก็ได้
เช่นสามารถกำหนดได้ว่า ทุกห้องในชั้นเรียนนี้ คาบ 5 วันพุธเป็นวิชาลูกเสือของทุกห้อง
แสดงว่าตอนนี้ วิชาลูกเสือจะไปลงตารางคาบเวลาของครูและห้องเรียนในชั้นเรียนนั้นๆ
สามารถ manual ลงวิชา ลงคายในแต่ละห้อได้ตลอด
จนกว่าจะพอใจ หลังจากพอใจแล้วถ้าต้องการ Auto ให้ระบบจัดตารางเรียนให้สามารถกด Auto จัดตารางสอนให้ได้เลย
ระบบจะไม่เอาวิชาไปลงทับคาบเรียนที่มีการเรียนการสอนของแต่ละห้องแล้ว
และที่สุดคัญคือระบบ auto จะไม่ลงวิชาซ้ำในวันเดียวกัน
เช่นห้อง 5/1 มีเรียนคณิต 4 คาบต่อสัปดาห์ แสดงว่าคณิตจะลงให้ห้อง 5/1 ไม่อยู่วันเดียวกันเลยจะต้องลงไปสี่วันเลยวันละคาบประมาณนี้
การจะลงคาบเรียนคาบสอน จะต้องเช็คด้วยว่า วิชาที่จะเอาไปลงนั้น ครูที่จะสอนว่างในคาบนั้นๆที่จะลงด้วยหรือป่าวถ้าลงไปแล้วก็ต้องไป stamp ให้ครูด้วยว่าครูคนนั้นมีการลงคาบนั้นวิานั้นไปแล้ว
ย้ำนะครูแต่ละคนสามารถสอนได้มากกว่า 1 วิชา
หลังจาก auto ไปแล้วถ้าห้องไหนที่ยังมีคาบว่างที่ไม่สามารถเอาวิชามาลงได้ก็จะต้องขึ้นให้เห็นด้วยว่าว่างคาบไหน และเหลือวิชาไหนที่ลงไม่ได้ user สามารถ manual ลงวิชาเองได้ด้วย 
ตอน user จะ manual ลงสามารถเลือกได้ว่าจะลงแบบลงแบบอิสระได้เลยคือจะลงแบบวิชาไม่ซ้ำกันในห้องนั้นๆในแต่ละวัน
ถ้าเลือกแบบไม่อิสระคือระบบจะตรวจสอบดูให้ว่า วิชาที่ user คลืกเลอกนั้นสามารุลงคาบไหนของห้องนั้นๆได้โดยไม่กระทบกับการเรียนการสอนของครูแต่ละคนด้วย
สามารถโยกย้ายวิชาได้ตลอด แต่การโยกย้ายวิชาแบบ manual จะต้องคำนวณเช็คกับครูตลอดเวลาว่าจะกระทบกับครูปลายทางมั้ยถ้าจะสลับคาบเรียนกัน อะไรประมาณนี้ 
การจัดตารางเรียนตารางสอนจะมีสองแบบตามที่เราบอกไปคือ
manual และ ออโต้
ระบบจะให้ความสำคัญกับการ manual เพราะจะถือว่าถ้า manual ไปแล้วจะล็อคคาบนั้นไว้เพื่อให้ตอน auto ระบบจะไม่ไปยุ่งกับวิชาที่มีการลงหรือคาบที่มีการลงไปแล้ว
การ manual สามารถโยดย้ายได้ตลอดแต่ย่ำดารจะลงคาบหรือลงวิชาจะต้องคำนึกถึงครูทุกๆคนที่มีความเกี่ยวข้องด้วยเสมอ
สามารถ clear คาบที่ระบบ auto ให้ได้เสมอ
ถ้า user โอเคทุกอย่างแล้วสามารถ บันทึกได้เลย ครูทุๆคนในโรงเรียนจะมองเห็นตารางเรียนตารางสอนทั้งหมด
สามารถ export ออกได้ด้วย 

function สอง : อัปโหลดเอกสารแผนการสอนของคุณครู
ฟังค์ชั่นนี้ เอาไว้ให้ครูแต่ละคนมาอัปโหลดเอกสารการสอนของตน
ในฟังค์ชั่นนี้ครูแต่ละคนจะมีสังกัดคือหมวดวิชาของตัวเองอยู่แล้วว่าครูคนไหนอยู่หมวดวิชาอะไร
และการอัปโหลดเอกสารแผนการสอนสามารถอัปได้ทุกวันเลย แต่ระบบจะต้องจำแนกและแยกให้เห็นว่าในหมวดวิชาแต่ละชั้นปีมีครูคนไหนบ้างและครูคนไหนอัปโหลดเอกสารแผนการสอนไปแล้วบ้างอัปวันไหนบ้าง
ในใจเราอยากให้ขึ้นเป็น calendar เลยแบบ ปฏิทินเลยว่าในแต่ละวันมีครูคนไหนอัปเอกสารไปแล้วบ้าง มีเอกสารอะไรบ้างสามารถโหลดและดูได้ตลอดเวลา
และจะมีการตรวจดูด้วยว่าแต่ละหมวดวิชาใครอัปแผนการสอนไปแล้วบ้างอัปอะไรไปบ้าง แล้วคนที่ตรวจจะเป็นไปได้ทั้งคนในโรงเรียน(มี user) และบุคคลนอกโรงเรียนเช่นคนในเทศบาล(ไม่มี user)
เราเลยคิดว่าครูในหมวดวิชาสามารถ Generate QRCode เพื่อให้บุคคลเหล่านี้สามารถเข้ามาดูเอกสารการอัปของแต่ละคนได้ แต่ได้แค่ดูแค่นั้นนะ ไม่สามารถโหลดหรือแก้ไขหรือลบได้
งง มั้ย

ข้อมูลที่ลงในโรงเรียนไว้เช่น ครู วิชา ชั้นเรียนอะไรพวกนี้
อยากให้ใช้รวมกันทั้งสองโซนเลยนะ

โซนสองคนที่ใช้งานได้จะเป็น บุคลากรของแต่ละโรงเรียน(ครู) เท่านั้นเลือกเข้าโซนสองแล้วเราอยากให้ UI สวยๆอลังการเลยเหมือน Netflix เลยเลือกดูเลือกเล่นเกมสื่อได้เลย

ตอนแรกก็อยากให้ระบบนี้เหมือนเป็นการจำรอง macbook เลยเหมือเข้าโปรแกรม อะไรพวกนี้
